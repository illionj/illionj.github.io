本笔记是作为2次学习使用

第一章
1.只由ascii字符构成地方的文件称为文本文件,其他称为二进制文件

2.系统中的所有信息都是一串bit,区分不同信息的方式是上下文

3.汇编语言非常有用,它为不同高级语言的不同编译器提供了通用的输出语言
例如:c编译器和Fortran编译器产生的输出文件使用相同的汇编语言

4.总线  它传送字节块叫做字 一个字的大小不尽相同
32位系统就表示它的总线字节块为32bit(4byte)

5.存储器层次的主要思想就是上一层的存储器作为低一层的高速缓存,本地硬盘就相当于网络文件的缓存
(人人是缓存)

6.操作系统的两个功能
a.防止硬件被失控的软件滥用
b.向应用程序提供简单一致的操作方式来控制复杂而大不相同的低级硬件

7.操作系统通过几个抽象完成上述功能
a.进程  对处理器,主存和io设备的抽象
b.虚拟内存  对主存和磁盘io设备的程序
c.文件 对io设备的抽象

8.进程 
进程提供一种假象,就好像系统上只有这个程序运行,程序看上去独占处理器 主存 和io设备
实现它的根本是cpu的上下文切换机制

从一个进程切换到另外一个进程是由系统内核控制的
注意:内核不是一个进程,相反它是系统管理全部进程所用代码和数据结构的集合

9.虚拟内存
它也是一个假象,仿佛每个进程独占主存

10.文件就是字节序列 仅此而已


第二章

1.经典表示
a.无符合 表示自然数
b.补码 表示整数
c.浮点数 表示小数

无符合和补码的问题是会溢出
浮点数则是因为精度问题 不可以支持结合率

相同的一串字节序列 可以表示不同的数字 重要的是它的上下文(你认为它是什么它就是什么)

整数的表示只能编码一个相对小的范围,但它是精准的
浮点数可以编码一个大的范围,但它是近似的

2.大多数计算机使用八位bit作为最小的可寻址内存单位 byte
也就是说 哪怕你只要1bit,寻址一次也会拿到8bit

3.字长 
字长 字  位  总线  它们都是关联的
总线传输的块就是字
大小就是字长
字长也是指针的标称大小
因此字长也界定了虚拟内存的寻址空间

参阅扩展阅读1

补充说明  可以4字节的总线操作8字节的数据类型
由于指针就是数据结构的首字节地址,数据长度有c编译器维护
操作是可以操作 但是比普通数据类型操作更加繁琐 而且会影响程序性能和稳定性
所以在32位系统上 long long int这种就不推荐使用
double可以使用(因为有专门的浮点运算单元),但是传输8字节需要分组,因此也会比float慢

因此指针一定是单个字的大小  

4.符号转化
有一个隐藏知识
c语言要求 当既要发生数据大小转变 又要发生无符号和有符号转变时
先改变大小(产生符号扩展),再改变符号
例如
short->unsigned int
是short -> int ->unsigned  而不是 short->unsigned short->usigned

符号运算有一点万变不离其宗
所有的运算都是二进制运算(包括溢出或者符号转化等)  其结果都是一样
运算后的结果根据选定的类型来解释

5.运算 
无符号的溢出检测 x+y>=x 当此表达式为真时  没有溢出
有符号的溢出检测 要检测正溢出和负溢出

在使用malloc之类的函数时 最好不要使用表达式 而是使用经过检查的值

6.浮点数 (参见扩展  二进制小数表示方法)
什么是浮点数
规格化
12345=  [00000000000000000011000000111001]
12345.0=[01000110010000001110010000000000]


                 11000000111001
0       10001100  10000001110010000000000   因为这个是规格化形式所以为尾数省略了原始编码的首个1
符号位  阶码       尾数

12345.0=1.1000000111001*2^13
阶码=13+bias=13+2^7-1=13+127=140=0b10001100
 
 
0.3=[00111110100110011001100110011010]

0 01111101 00110011001100110011010

0.3=0.0100110011001100110011010=1.00110011001100110011010..* 2^-2
阶码=-2+bisa=-2+127=0b01111101


c++ 中 double 也无法做到0.1+0.2==0.3


第三章 程序的机器级表示

p121 寄存器和操作格式

特殊规则:
1.生成1字节和2字节的指令保持剩余字节不变
2.生成4字节的指令会将高位置为0

mov指令中寄存器部分的大小必须与指令的最后一个字符相匹配
ps. 所以如果是寄存器复制到寄存器  那么这两个寄存器肯定一样大

栈的压入操作是 栈指针先减8  然后才把数据写入


3.移位操作
移位量可以是一个立即数,或者只能是单字节寄存器%cl中的值
(仅限%cl寄存器)

移位量由sal的后缀决定,%cl的寄存器低m位决定.
如果%cl的值为%FF,salb会移位7  salw会移位15 
%cl=  1111 1111 
salb  b=8 bit   2^3=8  m=3
所以salb只看cl的低3位  111   
0b111=7  因此移位7

4. 指令跳转
通常都是pc-relative

5.循环

do-while  
汇编会才有最基础的形式 body->test

while
低级别优化会使用中间跳转,即 先goto test

高级别优化会采用条件分支 即 将代码写成do while形式 但是在开始前检查test

for循环 也类似 只不过多了计算初始化值和值更新


6.switch

switch本质使用的是跳表技术 它主要是根据整数索引值
它的主要优点是执行开关语句与开关数量无关
gcc会根据开关的数量与值的稀疏程度进行优化 (开关数量多,值范围稠密更容易使用跳表)

switch会先优化index的范围,最后一个是默认的目标地址
编译器对switch的优化
相同操作的index只是使用相同的代码编号
缺失或超过范围的通通指向默认地址

7.过程
如果一个函数超过6个参数(针对linux),其他参数会入栈
入栈要求,必须八字节对齐.从右往左入栈.(第七个参数在栈顶)

寄存器组被所有过程共享,
被调用者保存 : 不能乱动
调用者保存:可以乱动

经常操作是把被调用者保存的寄存器组提前入栈,返回之前再弹出到原本寄存器
