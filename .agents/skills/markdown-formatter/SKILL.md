# Markdown 格式规范

仅修改格式和排版，不修改原文含义、措辞、结构或信息量。

## 备份

1. 修改已有文件前，将原文件备份到同级目录。
2. 备份文件名为原文件名加 `.bak`，例如 `README.md.bak`。
3. 已存在备份时，不重复创建或覆盖。
4. 新建文件不需要备份。

## 英文标点

1. 正文统一使用英文标点。
2. 中文与英文、数字之间保留一个空格。
3. 英文标点后保留必要的空格。
4. 不修改代码、命令、路径、链接和公式内部的字符。

## GFM 规范

1. Follow GFM's spec。
2. 不依赖 Markdown 编辑器的宽松解析行为。
3. 标题标记与标题文本之间保留一个空格，例如 `## Title`。
4. 列表标记后保留一个空格。
5. 嵌套列表、列表续行、代码块和引用必须正确缩进。
6. 围栏代码块必须闭合，并添加合适的语言标识。
7. 表格、链接、引用和强调语法必须合法且完整。
8. 文件末尾保留一个换行符。

## LaTeX 规范

1. 行内公式使用 `$...$`。
2. 独立公式使用以下格式：

```markdown
$$
公式内容
$$
```

3. `$$` 必须单独占一行。
4. 独立公式块前后必须各保留一个空行，不能与正文直接相邻。
5. 公式块内部只包含完整的 LaTeX 表达式。
6. 不允许公式块以 `=`、`+`、`-`、`\times` 等运算符开头。
7. 续写等式时，将前一项或完整左侧表达式一并写入公式块。
8. 不将普通文本写入公式环境。
9. 多行公式使用 `aligned`、`gathered` 或其他合适的数学环境。
10. 多行公式中的对齐点统一使用 `&`。
11. 换行统一使用 `\\`。
12. `\left` 与 `\right` 必须成对出现。
13. `\begin{...}` 与 `\end{...}` 必须匹配。
14. 花括号、圆括号和方括号必须配对。
15. 不使用未定义的 LaTeX 命令。
16. 不修改公式的数学含义，只修正分隔符、换行、对齐和语法格式。


## 禁止操作

1. 不润色或改写原文。
2. 不补充或删除内容。
3. 不调整章节或段落顺序。
4. 不修改代码、命令或公式含义。
